## 次に行う映像制作の優先順位
1. 桜華・レイナを同一人物に保つ基準画像を固定する。
2. `intro → rush → elbow → finish`の4本を最初の実写クリップとして制作し、動作接続を実機で確認。
3. `intro → evade → counter → finish`の回避から反撃への接続を作る。
4. 他ルートの入口差分（ショット元＋選択）を増やし、13シーン全体へ展開する。

**注意:** 単体のSVGシートを静止表示するだけで、2つの映像の動作が自然につながるとは限りません。手足の中間フレーム、画角、衣装や光の連続性は動画になった後に評価します。
