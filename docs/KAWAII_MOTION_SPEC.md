# KAWAII MOTION — 仕様・移行計画 v1.0
更新: 2026-11-05 / 対象: yz4git/newgame7 / iPhone Safari縦画面

## 作品の変更点
「GIF FIGHTERS: MOTION CHAIN」の戦闘から、**実写風ダンス動画を選び・つなぎ・演出して、ライバルとファンを奪い合う**ダンスパフォーマンスゲームへ全面転換。流用するのは映像分岐・固定カットポイント・リテイク・リプレイ・GIF/MP4割当の基盤のみ。対人格闘・負傷・HP・殴打などの演出は廃止する。

## ゲームの核
観客の「今求めるもの」を映像から読み取り、次の映像クリップを【キュート】【クール】【サプライズ】の演目から選択。動画途中で画面を止めず、選択は予約し、設定済みの編集ポイントで次へつなぐ。プレイ履歴はそのまま演舞リプレイになる。LIVE CUTの時間スクラブ機能は引き続き不採用。

### 1プレイ
- 桜華（プレイヤー） vs レイナ（CPU）の5つのパフォーマンス・ビート。
- 観客の好みはビートごとに変化する。画面上の観客サインと予兆を見て選択する。
- ライバルは毎ビート異なるスタイルで支持を獲得する。プレイヤーはファンの支持を増やし、一部を奪い返す。
- 同ジャンル連打には飽きられペナルティ。異なる動作・ジャンルをつなぐとチェーンと演出スコア上昇。
- 押す瞬間が中央値付近ならPERFECTボーナス。それ以外の判断窓でもGOOD。早すぎる入力は無効で減点なし。無入力は大きな損失。
- 途中で最大2回のリテイク。終了後は選んだ動画ルートの再生と結果が見られる。
- 最終的なファン数で「アンコール勝利／引き分け／敗北」が決まる。入力のみで勝てない状況を避けるよう5ビートの数値を調整。

## 動画シーケンス
- 動画ノード: opening, heart, step, sparkle, wink, groove, orbit, ribbon, disco, cheer, encore, silhouette, bow。これらは**戦闘カットの代用ではなくダンスの固有映像**。
- 各ノードは `id,title,scene,motion,duration,cueAt,window,cutAt,choices`。
- 各選択は `id,label,style,next,base,accent,description`。
- 5ビート後は集計結果により win/tie/lose の専用動画へ移動。
- ノードが再利用されても映像は繰り返しで変化する。データ駆動で最小限のクリップでも多様なルートをつくれる。
- ノードへの入場元によって、別の専用クリップを選択可能。素材契約は `assets/manifest.json` で `{ "heart":{"default":"assets/clips/heart.mp4","from":{"opening:cute":"assets/clips/heart_after_opening.mp4"}} }`。
- 実動画は先読み・接続姿勢を確認したもののみ配信。未制作のクリップはCSSアニマティックで明確に代替表示。

## 絵コンテ（仮素材用）
1. OPENING: 桜華とレイナが照明の当たる舞台に登場。観客がスタイルを求めるサイン。右端にレイナ。
2. HEART / WINK: 桜華のハートポーズ→カメラへウインク→ファンのハートが増える。
3. GROOVE / STEP: 足のリズム、髪・衣装のスイング、ダイナミックなターン。クール観客が反応。
4. SPARKLE / RIBBON: 照明が変わり、リボン・衣装エフェクトが追加される。サプライズ観客が急上昇。
5. CHEER / ENCORE: ファンと掛け合い。前回と異なるアピールを選べば盛り上がる。締めはアンコール／同点／静かな退場。

## キャラ基準
- 桜華: 成人女性、黒髪・赤いリボン・桜の髪飾り、深紅と金のダンス衣装。キュート系の華やかさが強いがクール系も可能。
- レイナ: 成人女性、ダークブラウンのまとめ髪、濃紺・銀のスポーティーなダンス衣装。クール系の鋭い動きが得意。
- どちらも格闘ではなくステージパフォーマー。互いへの攻撃、流血、衣装破損などは描かない。

## UI/UX
- ステージ映像を画面の大部分に、ファン数・応援ゲージ・観客のリクエスト・3択を下部へ。
- タイミングバーは映像を見ながら把握できる小型表示。選択確定後はLOCKEDを表示して自然に次カットへ。
- iPhone Safe Area / 同時タッチ / ズーム誤作動 / 不要なスクロール / 低画面高を対策。
- 動作の代替素材を「ANIMATIC」と表示。実写GIF/動画を実装していない時に実写と偽らない。
- 音声: 初回タップ後にWebAudioで原創の短いSEを合成（デフォルトはユーザー操作に従う）。非音声でもゲームが成立。

## 受け入れ条件
- ゲーム開始→5回の分岐→結果の1プレイが完走する。
- 選択したジャンル・観客の好み・前回のジャンルで獲得ファンが変化する。
- 相手の応援ファンが各ビート変化し、双方を比較して勝敗が決まる。
- リテイクで前の選択をやり直し、スコアとファン数が完全に復元される。
- リプレイで選択順・分岐映像・同じ結果を再現する。
- 未登録メディアはCSSのダンスデモへフォールバック。GIF/MP4ファイル割当は動作する。
- 自動テストとGitHub Pages公開が成功する。
