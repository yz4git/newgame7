# KAWAII MOTION — 動画制作・字コンテ v1.0
2026-11-05 / iPhone縦画面向け / **旧格闘絵コンテの代替**

## カメラ・素材の基本
- テーマ: ダンス競演、ファン獲得、笑顔、舞台演出。人への攻撃・接触格闘・負傷なし。
- 主人公「桜華」: 成人女性、赤・金のダンス衣装、桜髪飾り、赤いリボン、しなやかな動き。相手「レイナ」: 成人女性、紺・銀の衣装、実戦的なリズム感があるパワフルなダンス。
- 画面: iPhone縦画面。マスター縦3:4または9:16で構図を固定し、顔・目線・手先が端で欠けないようにする。決めポーズでは全身を一度見せる。
- **動画が分岐**: 選択を入力しても即カットしない。シーンの90%の時刻付近にある**編集ポイント**に到達してから次へ。前後の最後のポーズと開始ポーズを揃える。過剰な暗転で無理に接続しない。
- 観客のサイン: ハートのペンライト=かわいい、青いライトとリズムの歓声=クール、星とスポット照明=サプライズ。音無しでも識別できる。
- 音響: 自作ビート、観客コール、衣装と足音。使用許可のある素材に限定する。
- 素材: 720×960または1080×1440のH.264 MP4が基本。GIFはプレビューと短い装飾ループ用。60fpsを必須とせず、動き・画質・容量を確認する。

## 基本5ビートのプレイ
1. **OPENING**: 2人が登場。観客がジャンルの好みを示す。プレイヤーが最初の演出を選ぶ。
2. **FIRST APPEAL**: 選んだハート／ステップ／光の演出が再生。客席が反応。次を決める。
3. **STYLE CHANGE**: 別ジャンルへ移ると新鮮さが増し、同ジャンル連打では観客が飽きる。
4. **CROWD CALL**: 桜華とレイナが交互に観客へ応え、ファン支持を取り合う。
5. **FINAL APPEAL**: 最終演出を選び、勝敗に応じたエンディングを再生。

## 最初に制作する6本のクリップ（1プレイの実写テスト）
**opening → heart → step → finale → heart → step** （5回選択＋最終演出）。

### SHOT 01 / opening / 3.50秒
- 0〜0.8秒: ライブ舞台。画面左に桜華、右にレイナ。舞台に花びらとハートの光。
- 0.8〜1.6秒: 観客のハートライトが増え、桜華が視線を客席へ。
- 1.6〜3.15秒: 次のアピールを選択する観客の予兆がわかる。軽く身体を左右に揺らす。
- 3.15秒: 選択した次の演舞の入口姿勢へ接続。
### SHOT 02 / heart / 3.20秒
- 0〜0.6秒: 手が胸の前に戻り、両手ハートをつくる。
- 0.6〜1.5秒: 目線をカメラに向け、顔と肩・腰を連動させてハートポーズを完成。
- 1.5〜2.9秒: くるっと身体をひねり、次のクールな足元ステップが自然に始まる姿勢へ。
- 2.9秒: 次へ接続。
### SHOT 03 / step / 3.20秒
- 0〜0.8秒: 桜華の前脚を映してテンポ良く踏み替える。
- 0.8〜1.5秒: 上半身はカメラへ、腕と脚の動きを同時に見せる。
- 1.5〜2.9秒: リズムを切り返して光のフィナーレへ。
### SHOT 04 / finale / 3.60秒
- 0〜1秒: 高速のポーズ転換を2つ。衣装と髪紐の慣性を表現。
- 1〜2.6秒: ダンスの山場でライトが画面を横切り、次のカットへ自然につなぐ。
- 2.6〜3.24秒: クライマックスを明確に見せる。
### SHOT 05 / heart / 3.20秒
- 前回のheartと違う入口映像を用意。直前の光の動きからハートをつくる。
- 3.20秒のうち2.88秒を接続点にする。
### SHOT 06 / step / 3.20秒
- フィニッシュの足運びを再度強調。ラストは客席へ大きく手を振る。
- 映像終了後に支持率判定を反映した win / tie / lose の動画へ入る。

## 入口差分のルール
- `node.id@previousNode:choiceId` をキーにして入場元専用動画を再生できる。
- たとえば `heart@opening:heart` と `heart@finale:heart` は別動画でも良い。
- 入口ごとに「頭・目線・両腕・体幹・足位置・衣装・カメラ角度・光の方向」をチェック。
- **既存ノードの1本動画が全ルートに合うと保証するものではない**。入口差分を後から増やす。
