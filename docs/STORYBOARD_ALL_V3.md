# GIF FIGHTERS — 全13ショット縦構図・接続統一仕様 v3
作成: 2026-11-05 / フォトリアル映像素材制作の前段階 / repository `yz4git/newgame7`

## 改訂の位置付け

本資料は [縦画面の改訂絵コンテ v2 (CUT 01〜03)](STORYBOARD_VERTICAL_V2.md) の続編。
**CUT 04〜09 / X1 の判断シーン7本、CUT 10 / 11 / XX の結末3本**を詳細化した。これで13ショットを同じ演出・操作ルールで制作できる。

採用するゲーム性は **MOTION BRANCH**。**LIVE CUTの時間軸スクラブは採用しない。**
プレイヤーは敵の肩・重心・予兆を観察し、戦術を選択する。選択が確定しても映像を即停止せず、事前設計したカメラ／動作の接続ポイントで次のショットに進む。

### 共通ルール
- マスター絵コンテ: 縦3:4 (1080×1440暫定)、端末の画面は縦長。重要動作は画面中央の安全領域。
- 桜華は深紅×金、画面左。レイナは濃紺×銀、画面右。視線、脚、肩、軸足の整合性を維持。
- 場所は「格闘映画のロケ地編集」。桜屋上→雨路地→ネオン街→朱色の寺院へ移ってよいが、接続は拳・袖・柱・水面反射を利用し、単なる突然の背景差替は禁止。
- 判断ウィンドウ内は押した時点で選択予約。**接続点まで再生してから次ノードを表示**。予兆より前の早押しは失敗にせず無効入力、最終的に無入力なら失敗ショットへ。
- 視覚的なヒットは接触フレームだけでなく、腰・肩・衣装・表情・着地の演技で表現。誇張した血や損壊は不要。
- **時間は撮影・生成用の目安**。現行 `graph.js` の`duration/window/cutAt/cueAt` と連動させる。静止画ルックとゲームの入力時刻は混同しない。

## 全ルートで必要になる映像接続アセット

### 接続の約束（13ショットのうち10判断ノード／30分岐）
`graph.js`の各choiceには行先が設定されているが、**30のエッジを単純な映像の連続再生で自然につなぐことはまだできない**。それぞれについて以下のチェック欄を設ける：

|項目|確認条件|
|---|---|
|方向|桜華の移動が画面左→右／対戦軸を跨がない|
|身体|前の出口と次の入口で頭・肩・肘・膝・足が一致|
|相手|レイナのガード／崩れ／空中姿勢が一致|
|照明|場所が変わる時は遮蔽や意図したマッチカットを挟む|
|時間|選択時刻と実際の映像カット時刻は別に記録|
|画角|iPhone縦画面で主体が小さすぎず手足の軌道が読める|
|失敗|全ノードから共通ミス映像への接続が可能|

### 動画の導入順
1. **CUT 01→02→05→10** の4ショットで一本の実写アクションが成り立つか確認。
2. **CUT 01→03→07→10** の回避→反撃で拳の遮蔽カットが成立するか確認。
3. **CUT 01→04→06→11** の演舞系で異なる終幕も成立させる。
4. **CUT 01→03→08→09→10** のロケ地転換のあるルートで人物・照明の一貫性を確認。
5. 最後に全30分岐の入口差分と失敗ルートを検証。

### 絵コンテの閲覧
`docs/storyboards/` の各SVGは**構図・ポーズ・カメラ軌道の下書き図**。写真的な完成素材ではない。
CUT 01〜03に続き、CUT 04/05/06/07/08/09/X1/10/11/XXの縦フレームシートを追加する。
