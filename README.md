# 深界の織り手 / DEEP WEAVE

スマホ縦画面のための、**完全ターン制・指一本操作のクラシックローグライク**。旧GIFダンスゲームを置き換えます。静的なHTML/CSS/JavaScriptだけで、CDNや外部素材は不要です。

## 操作

- **タップ**：床なら移動。離れた床は安全な範囲で自動移動。敵に近づくと停止。隣の敵をタップすると攻撃。
- **スワイプ**：上下左右・斜めの確実な1歩。仮想スティックも十字キーも不要。
- **長押し**：敵・アイテム・地形の情報。長押しドラッグで目的地指定。
- **道具を使う**：鞄から選んで、盤面の対象をタップ。治癒薬は即使用。
- **待機**：1ターンを消費して敵や火を動かす。
- **一歩が一手**：行動しなければ敵も動かない。メニュー操作・考えている間は時間停止。
- **死亡で終了**：持ち込みなし、12階層。進行中はブラウザのローカル保存から再開できます。

## 12層の深淵

27×29マスの階層自動生成、視線を遮る壁と煙、7種の敵と8種の道具、針罠、育成アイテム、4つの環境テーマ。

環境連鎖：水+雷=感電、水+氷=凍結、油/茂み+炎=延焼、風+敵+罠/火=追加ダメージ。単なる数値の強さより状況判断を重視します。

iPhoneのSafariを念頭に、Canvas描画と誤ズーム・誤スクロール防止のタッチ入力を用意しています。外部の画像・動画・音楽はありません。WebAudio効果音は初期状態でOFFです。

## 開発とテスト

ファイル：index.html, style.css, engine.js, game.js, manifest.webmanifest, icon.svg

開発時は 'node tests/engine.test.cjs' でエンジンテストを実行できます。'python3 -m http.server 8765' でローカル起動。GitHub ActionsでCI、iPhone相当のChromium/WebKitプレイチェック、Pagesデプロイを実行します。

このブランチから元のGIF/MP4、ダンスエンジン、絵コンテ、旧テストを取り除きます（過去のGit履歴には残ります）。他のリポジトリは変更しません。

**初版**：操作と戦術ループを検証するプレイアブル版。追加キャラクター・多彩なアニメーション・BGM・大規模ストーリーは後続の品質向上課題です。

## 起動時だけの自動更新（v0.4）

- 起動時に `version.json?startup=<timestamp>` を `cache: no-store` で1回だけ取得し、GitHub Pages側に公開されたコミットSHAと比較。
- HTMLそのものが古い時だけ `?dwv=<SHA>` へ1回移動して、最新版の画面構成を取得。無限リロード防止あり。
- ゲームスクリプト（engine.js/game.js）も版指定 `?v=<SHA>` で読み込み、CSSにも同じ版を適用。
- 通信障害時は手元の版で起動。ゲーム中の定期監視や勝手な再読込はなし。プレイデータは従来どおりローカル保存。
- 公開処理で `scripts/stamp-release.cjs` が現在のコミットSHAをindex.htmlとversion.jsonに埋め込む。ゲーム内容の更新ごとに手動でバージョン番号を編集する必要はありません。

## v0.5：iPhone下部システムUIとの重なりを解消

## v0.6：実際のテストプレイ結果から戦術性を強化

- 周囲2マス以内の罠を発見可能に。黄色の警告マークで表示。自動経路は罠を高コストで避け、踏む場合は隣接操作を2回確認する。
- 角で塞がれた斜め攻撃は自動回り込み経路を探索。敵が通路を塞ぐ場合でも階段への経路を計画でき、実際に敵へ接近した時点で停止。
- 地形を連結した6〜10マス程度の小区画として生成し、敵を水・油・草の内部または隣に配置する比率を増加。感電・延焼・凍結・吹き飛ばしを狙いやすくした。
- 射手と火術師に1ターンの予告動作と画面警告を追加。予告中に移動して避けたり、氷で止められる。
- 序盤の敵密度と罠を抑え、階層移動時にHPを6回復。ダンジョン床と岩壁の色差を拡大し、ログをタップして直近の戦闘記録を見られる。
- メイン盤面は9×11表示のまま。端まで広げるデザインとシステムUIを避ける固定操作バーも維持。


## v0.7 — 属性連鎖エディション

- **ダンジョンの大部分が属性床**：床の約80〜90%が水・油・草・氷。既存の部屋・通路は維持し、近い属性がまとまった領域になります。生成100シードで平均約86%を確認
- **自分の技による炎ではダメージを受けない**：火種から広がる炎もプレイヤー起源のまま伝播して無害。敵の火術・従来の中立炎は有害。プレイヤー炎は金色、敵の炎は赤色で区別できます
- **実際の属性伝播を可視化**：エンジンが計算した水脈の雷伝播、氷結、火の延焼、突風、煙、回復の各領域を、段階的なマスの光と移動する光の線で表示
- **属性技ワンタップ**：下部「✦ 属性技」ボタンが、敵の配置・属性床・所持道具から有効な技と対象を自動提案。発動可能なら光り、押すだけで1ターン使用。技は所持道具を1個消費。好きな対象を選ぶ従来の「道具」メニューもそのまま使用できます
- **保存中の旧ダンジョンにも適用**：以前のバージョンのセーブが読み込まれたら、壁・進行度・敵配置・発見済みエリアを保ったまま属性床を増やします。更新のために冒険を最初からやり直す必要はありません
- **縦画面・下部操作バー維持**：画面端までの9×11マップ、Safariホームインジケーターを避ける固定操作ボタンを維持し、4つのタッチボタンを配置

確認方法：node tests/engine.test.cjs、GitHub ActionsのChromium/WebKitモバイルテスト。

## v0.8：画面上に常時表示するログ

- 戦闘・移動・道具の最新ログ3件を半透明パネルで画面下部の操作バー直上に固定（低い画面は2件）。マップと重なっても消えない
- パネル全体はタップを透過するため、重なったマップをタップ・スワイプ可能。「履歴」ボタンだけタップして過去12件を確認できる
- 最新行と以前のログを色分けし、ターン番号も表示。新しい行動や敵の反応があるたび即時更新
- ダンジョンや画面サイズを縮小せず、Safariのホームインジケーターを避ける固定ボタンは維持


## v0.9：レビュー反映 — 属性戦術、補充、ログ・視認性

- **未発見敵の自動検知を禁止**：属性技の自動提案は現在視界に入っている敵だけで判断する。水・氷を通った物理的な雷は視界外にも伝わるが、未知の敵を提案条件に含めず、見えない敵の撃破はログで知らせない。
- **隠れた140マス制限を撤廃**：雷・氷は接続した領域の全マスへ届く。エンジンの伝播マスを省略せず同じ座標で描画し、連鎖の長さに合わせて波が進行する。描画は未探索エリアを透視しない。
- **敵と距離による属性相性**：雷のダメージは伝播距離が長いほど減少し、水精には強く石の衛兵には弱い。氷による足止め、火の延焼、風の壁・罠への吹き飛ばしも使い分ける。
- **後半の技不足を改善**：4体討伐ごとに技1個を補充し、次の階へ進んだ際にも1個支給。道具袋の8枠を超えない。階層移動時のHP回復は6から7へ増加。
- **ログのターン番号修正**：移動・攻撃・罠・技・待機のプレイヤー行動開始時にターンを確定し、その行動で起こったメッセージを同じ番号に揃える。雷は見えている対象の命中体数、ダメージ、撃破数を要約。
- **視覚的な属性の境界と予告**：属性地形の境界線と質感差を追加し、雷のワンタップ提案時に現在見えている連鎖ルートを盤面にプレビュー。未探索の敵やルートはハイライトしない。

検証：エンジンの回帰テスト（未発見敵への提案、199マス連鎖とVFXの同一性、旧セーブ、技補充、ログのターン一致、敵の属性相性）およびChromium/WebKitのiPhone相当操作テスト。

## v0.10 — 透過ミニマップ／透明ログ

- 戦闘ログの背景を従来より大幅に透明化し、マップが下に重なっていても見えるように変更。操作が通り抜ける仕様と「履歴」ボタンは維持。
- ゲーム盤面右上に不思議のダンジョン風の27×29全体ミニマップを半透明で固定。探索した部屋・通路・壁のみ描画し、未探索の地形は隠す。
- 現在地を黄色、発見済み階段を橙色、視界内の敵を赤色、視界内のアイテムを紫色で表示。敵・アイテム・罠を透視しない。
- ミニマップはタップを透過し、重なっているマスも操作できる。プレイヤーの移動・階層移動・ロード・画面回転でも更新。マップ自体のサイズを縮小しない。
